# NEM Test rapport - PDF template design

Claude Design canvas: https://claude.ai/code/artifact/47f8b864-2c41-44f4-b277-ffa958c213ba

Working files for the canvas. `Main.dc.html` is the report with the olive header (the chosen
direction; the white-header variant was dropped). Anatomy follows `../build/report-template-example.html` (same slots and
section labels). Colours are the live Webflow tokens on site `69bfba56f3622791a798b816`
(`--color--black` #292828, `--color--olive-medium` #706d56, `--color--grey` #9f9c8b,
`--color--light-grey` #ecebe8, `--color--accent` #fafa7d). Fonts are the site's Lato + Montserrat.
`logo-dark.svg` is the icterine logo recoloured (NEM olive, Life black) for white backgrounds.
Sample copy is a hand-written illustrative report for the false-hope > self-rejection profile
written to the five-field spec in the system prompt; it is not model output.
