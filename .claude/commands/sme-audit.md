Run a fixed-scope website and online-presence audit for a small business: report, GBP copy pack and work plan. Read-only on the live site.

## Usage
`/sme-audit <client-slug> <url>`
- `<client-slug>` — folder name under `projects/` (e.g. `example-practice`)
- `<url>` — the live site root (e.g. `https://www.example.com`)

## Steps
Follow `.claude/skills/sme-audit/SKILL.md`, Phases 0–10 in order, passing `<client-slug>` as `<client>` and `<url>` as the site to audit.
